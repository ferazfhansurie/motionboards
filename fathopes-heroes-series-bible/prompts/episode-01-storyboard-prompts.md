# Episode 1 Nano Banana Storyboard Image Prompts

Use these for five multi-panel storyboard images. Each image is one storyboard sheet representing one 15-second section of the 75-second episode.

Pipeline:

- One Nano Banana generation = up to 3 character reference images + 1 prompt = 1 storyboard sheet.
- Each storyboard sheet must contain 4 cinematic comic panels inside the same image, showing the full 15-second sequence from start to finish.
- Format requirement: the final storyboard sheet must be vertical 9:16, arranged as a clean 2x2 grid. Each individual panel inside the sheet must also be vertical 9:16.
- The generated storyboard sheets will later be used as visual references for Seedance video generation.
- Do not ask Nano Banana to create motion. Ask it to create 4 still panels that clearly show the action progression.
- Include the complete script/action beat inside each prompt as context for expression, pose, and staging. Do not render dialogue text in the image. Do not stop interpreting the scene at the first line of dialogue; use the full script beat to understand all panels.

## Global Visual Rules For All 5 Images

Storyboard sheet format:
Create one vertical 9:16 storyboard sheet containing exactly 4 cinematic comic panels in the same image. Arrange the sheet as a clean 2x2 grid. Each of the 4 panels must also be vertical 9:16, like four phone-screen frames placed inside the larger vertical storyboard sheet. Every panel must be clearly separated with thin clean gutters. Each panel must show a different moment, camera angle, and action beat from the 15-second sequence. Do not create a single scene. Do not add panel numbers or text labels.

Style:
Mixed-media animated comedy storyboard. 2D anime-inspired FatHopes characters composited into a realistic Malaysian mamak/warung back alley. Real photographed environment, wet concrete floor, open longkang drain, plastic stools, fryer/kitchen props, buckets, oil stains, fluorescent lighting, practical Malaysian food-business details. Clean bold character line art, expressive faces, natural staging, cinematic panel compositions.

Mixed-media texture rule:
The real world must stay realistic 3D/photographic: believable wet concrete, real metal tong, real oil stains, real fryer area, natural shadows, lens depth, practical lighting. The characters must look like 2D comic/anime cutouts living inside that real world: visible ink outlines, subtle halftone/comic paper grain, hand-drawn shading, slightly flatter colors, expressive face shapes, and crisp cel-shaded highlights. Let the contrast between real-world texture and comic character texture be obvious and charming. Aim for a playful mixed-reality cartoon feel with absurd comedy in ordinary life, without copying any specific existing show.

Eye-catching rule:
Every storyboard image should contain one memorable visual hook that pulls the eye immediately. This can be an exaggerated prop, unusual perspective, expressive character pose, weird tiny environmental detail, or a one-off background character/object. Keep it grounded in the Malaysian warung world and do not let it distract from the main action.

Continuity:
All five images happen in the same warung/mamak back alley. Keep the longkang drain, oil container, proper tong, vendor uncle, lighting direction, and spatial layout consistent. Early images are busy daytime/kitchen-hours. Later images shift to quieter evening with darker alley shadows.

Character reference labels:

- `@kit_ref`: Kit, stocky hardworking male field operator in teal jumpsuit with reflective bands, black gloves, black boots, practical tired expression.
- `@sparron_ref`: Sparron, blonde woman with green glowing glasses/visor, black top, green pants, tactical pouch, sharp strategist.
- `@drup_ref`: Dr.UP, male in white long coat, dark green inner shirt, black pants, black gloves and boots, calm confident operator.
- `@glinciro_ref`: Glinciro, hat-wearing G.O.M. villain, calm elegant posture, unsettling smile, 70% Malay / 30% English Manglish energy.

Vendor:
Older Malay uncle, local warung/mamak owner, simple shirt/apron, tired practical expression, Bahasa Melayu only. He is not a superhero reference image unless you have one; generate him as a grounded local character.

Universal negative prompt:
No text overlays, no subtitles, no captions, no speech bubbles, no title cards, no UI text, no readable labels, no watermarks. No cyberpunk, no futuristic neon, no glossy corporate ad, no Marvel-style superhero spectacle, no fantasy setting, no full 3D Pixar style, no extra random superheroes, no robots, no weapons, no lasers, no city destruction, no huge explosions, no readable text walls, no big logos, no changing outfits from references, no young vendor, no Glinciro stealing the tong, no black liquid entering the oil. Do not make the real environment look illustrated; the environment stays real 3D/photographic while the characters stay 2D comic-textured. Keep it grounded and cinematic.

Unique storyboard activity rule:
Each storyboard sheet must show a different activity and camera language. Do not repeat the same medium group shot across panels. Use these five visual modes:

1. Low drain-level action save.
2. Over-shoulder diagnostic scan and practical explanation.
3. Wide evening progress/montage sheet.
4. Dutch-angle villain reveal from shadow.
5. Dynamic action triangle with lid block.
