# FatHopes Threads Content Planner

Goal: grow the `farzmus` Threads account like a real KL money-life account first, then make FatHopes feel like a natural discovery. The first 1-2 days must not behave like an influencer. No "korang?" prompts, no advice-thread posture, no obvious audience farming.

Cadence: 2 posts/day, 8am and 8pm MYT.

## Engagement Ramp

| Days | Behaviour | Copy rule |
|---|---|---|
| 1-2 | nobody knows you | short personal statements only, no questions |
| 3-4 | warming up | mostly statements, rare soft question if natural |
| 5-7 | light conversation | some questions, still low-pressure |
| 8+ | community mode | reply-pullers allowed, still not bait |
