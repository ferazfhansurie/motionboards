# PUSH Collector Identity — v4 Master-Mural Method

## Why v3 failed

The lime cable technically crossed the card edges, but every panel was generated as a separate warehouse image. The camera, perspective and lighting reset at each crop, so it still read as seven unrelated posters.

## New visual direction: the PUSH case-file ribbon

This is one continuous premium security dossier, not one continuous physical depot:

- Matte charcoal-to-deep-green paper/metal background across the complete width.
- A subtle, oversized FatHopes Energy logo watermark only in the opening card background.
- One consistent lime evidence line and case-number/footer rail across every crop.
- Repeated physical elements are deliberate: clipped evidence photos, verification stamps, app-screen cards and a final case-closed seal.
- The opening card is a minimal title card; it has no depot scene behind it.
- Each informational beat is concise, large and legible. No long supporting copy generated inside the image.

## Generation construction

Generate three wide 21:9 Nano Banana 2 master murals, then crop the fixed three-card sections. This makes the interior seams pixel-continuous:

1. **Master A — slides 1–3:** Identify / Uniform Front / Uniform Back.
2. **Master B — slides 4–6:** Vendor App / Mini Tanker / Get Verified.
3. **Master C — slide 7:** Case Closed.

Only two joins need controlled matching (A→B and B→C), using the previous master’s outer edge as a reference. The routine is: generate master → crop → inspect a stitched preview → make a targeted master replacement only if the shared rail or background fails.

## Fixed design rules

- 4:5 crop ratio for every card.
- First-card backdrop: FatHopes official logo watermark only.
- Large exact labels only; no tiny generated UI copy.
- No neon cable pretending to travel through a photo-real depot.
- No invented FatHopes logo on clothes, vehicles or app UI.
